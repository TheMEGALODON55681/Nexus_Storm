# Sample Outputs

This folder contains sample articles generated by Knowledge STORM to demonstrate
the kind of output you can expect from the pipeline.

Each sample includes the final polished article. The articles below were generated
end-to-end using the default settings:

- **LLM:** Google Gemini 1.5 Flash
- **Retrieval:** DuckDuckGo
- **Pipeline:** Full 4-stage (research → outline → article → polish)

## Generating Your Own

To produce a sample like the ones above:

```bash
python examples/storm_examples/run_storm_wiki_gemini.py \
    --output-dir results/my_article \
    --retriever duckduckgo \
    --do-research \
    --do-generate-outline \
    --do-generate-article \
    --do-polish-article
```

When prompted, enter a topic of your choice. The final polished article will be
saved as `storm_gen_article_polished.txt` in the output directory.

> **Note:** Output quality and length vary depending on the topic, retrieval
> results, and the LLM model used. Niche or recent topics may produce shorter
> articles due to limited public information.
